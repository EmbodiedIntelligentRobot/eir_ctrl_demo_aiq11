# 感知策略 9500

`config/pro_perception_9500.yaml` 同时加载 9500 感知行走（41）、当前 AMP WALK（28）和 MIMIC A–E（30–34）。遥控菜单包含这些策略及 STILL、READY。默认使用 CPU float32、LibTorch、合并推理，所有策略共用所选后端。

## 启动

先按应用 README 编译并加载 ROS 和消息包环境，然后在工作空间根目录执行：

```bash
/tmp/eir-ctrl-build/apps/eir_ctrl_demo_aiq11/eir_ctrl_demo_aiq11
```

该组合已设为程序默认配置，无需传 YAML 或设置 `AIQ11_PRO_MODEL`，可从任意工作目录启动。配置位置由构建时源码路径确定，模型相对配置文件定位；移动源码目录后需重新配置构建。显式传入其他配置的用法保持有效。

退出时在启动终端按 **Ctrl+C**，控制进程会清理关联 GUI。当前仅关闭 MuJoCo 窗口会中断反馈并触发故障锁定，控制进程仍驻留，需再用 Ctrl+C 退出；仅关闭遥控 GUI 也不会结束仿真。

STILL → READY，等待 `ready=true` 后切换感知行走、AMP 或 MIMIC；策略之间可以直接切换。READY 到位后自动释放悬吊。感知模式下自动打开深度窗口，显示 `/perception/depth/image` 的 32×18、32FC1 米制图像。

GUI 速度限值取 AMP 与感知配置的交集：`vx [-0.8, 1.0] m/s`、`vy [-0.55, 0.55] m/s`、`wz [-1.0, 1.0] rad/s`。这是命令范围，不是运动质量验收结论。

此入口同时通过 `motion_stream` 加载上半身离线动作并提供 `/motion_cmd` 服务。进入 **AMP WALK** 后，可执行 JOF11 奥特曼、JOF12 欢呼、JOF13 加油、JOF14 再见；GUI 从动作配置读取实际支持的列表。STILL、READY、感知行走和 MIMIC 不允许播放，GUI 会提示仅支持 AMP WALK。故障锁定时须排障并重启，不能直接解除锁定播放动作。播放、STOP 和交回规则见[上半身离线动作](上半身离线动作.md)。

基础 `pro.yaml` 不启用感知；`pro_perception.yaml` 仍使用原感知模型。恢复后的 9500 入口共存 AMP/MIMIC，与 2026-10-09 独立分支中仅加载模式 41 的入口不同。

## 模型来源与契约

资源从 loop 的应用提交 `04d4b31` 原样恢复，位于 `policies/perception/pro/lip_mixed_push_9500/`；该提交此前只在 `policy/lip-perception-9500` 分支。

- 训练运行：`2026-10-08_11-06-12_lip_perception_mixed_push_4096`，checkpoint `model_9500.pt`。
- 合并 TorchScript SHA256：`959f451a1a292bec1fcf41565332c9b898f8f67730f5a3acaf44b744f9a32e11`。
- 输入 `[1,5232]`：624 维本体历史与 8×18×32 深度历史；输出 `[1,23]`，50 Hz。
- 深度编码器为 CNN，动作网络为五专家 MoE；模型没有跨调用的循环隐状态。
- 配套六份合并/拆分 TorchScript、ONNX 模型及原始导出记录一并保留；默认运行合并 `policy.pt`。
- 深度处理为 `parkour_depth_v2`；关节顺序、默认姿态、缩放、PD 增益、维度与模型 SHA256 由 `manifest.json` 校验。

机器人参数、机构映射、故障锁定和线程隔离沿用当前主线。推理与 ROS 发布在普通线程执行，控制应用仅允许仿真。

## 验证

配置完整 PRO MJCF 的双后端构建可执行：

```bash
ctest --test-dir /tmp/eir-ctrl-build \
  -R '^ctrl_ros_perception_9500_' --output-on-failure
```

两项回归分别使用 ONNX 和 LibTorch，验证悬吊 STILL → READY → 感知，速度输入、深度图、AMP/MIMIC A–E 与感知的切换，以及返回 STILL。完整 PRO MJCF 路径通过 `EIR_CTRL_SIM_TEST_MODEL` 指定。

历史 9500 地面前行测试曾触发倾角保护；当前主线已调整倾角保护行为，旧记录不能替代当前版本的运动验收。短时悬吊回归不能证明地面行走或爬楼稳定，长时运动、真实相机及硬件仍未验收。
